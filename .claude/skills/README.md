# プロジェクト用スキル

このディレクトリの日本語ライティング・チェックスキルは、外部プロジェクトから取り込んだものです。

## 収録スキル

- **jp-style-check** — 日本語の明快さ（簡潔・明快・誤解されない）とカルク（訳語臭／翻訳調）を点検する。`/jp-style-check`
- **logic-jp-check** — 上記に加えて論理・論証の妥当性（主張と根拠、演繹・帰納、MECE、因果）も点検する。`/logic-jp-check`

## 使い方

文章の下書きを渡して「カルクを直して」「日本語を整えて」「ロジックチェックして」などと頼むと起動します。ノートや記事を書くたびに、同じ基準で欠陥だけを指摘してくれます。
